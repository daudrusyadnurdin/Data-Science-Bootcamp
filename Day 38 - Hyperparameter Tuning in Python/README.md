# Assignment Intro:
- Hyperparameter tuning is the process of finding the best combination of hyperparameter settings in a machine learning model for optimal performance (e.g., higher accuracy, lower error).
- This assignment will test a machine learning model to predict customer churn, allowing the marketing team to implement actions (such as promotions, incentives, points, and other marketing initiatives) to prevent customer churn (retention program).
- The baseline models used include: Logistic Regression, Random Forest, XGBoost, and LightGBM. Ultimately, XGBoost was selected for hyperparameter tuning, as it performed best based on testing.
- Tuning was performed using the Randomized Cross-Validation method. After testing, the performance of the XGBoost model was significantly improved.
