
# Assignment Intro:
- This assignment is an attempt to practice customer segmentation using the RFM (Recency, Frequency & Monetary) analysis approach and presented using the Power BI tool.
- This is the first time I've been exposed to RFM analysis and using Power BI. Therefore, not much is expected of this assignment, actually.
- In this assignment, in addition to exploring customer segmentation using RFM, students are also asked to provide recommendations for each segment, based on the analysis results.
