# Assignment Intro:

- The data used is data from a telco company related to customer churn. Therefore, the data contains a column indicating whether a customer is in Churn status (=Yes) or not (Churn=No).
- In this assignment, to explore machine learning models, I used Random Forest and Gradient Boosting to compare their performance.
- Because the data is imbalanced, this assignment attempted to use the SMOTE oversampling method, specifically for the churn data.
- In this assignment, the performance of the two models was compared with the original imbalanced data and the data that had undergone SMOTE oversampling. In theory, the performance should be better, but this assignment requires concrete proof of this method.
